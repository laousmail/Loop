      Settings

      Browsers can only read public Drive folders through Google’s API, so the app needs a free key. It stays on this device.

      How to get a key (about 2 minutes)
      1. Open Google Drive API in Google Cloud, create or pick a project, and select Enable.
      2. Go to Credentials, select Create credentials → API key.
      3. Recommended: under the key’s restrictions, limit it to the Google Drive API and to this site’s address.
      4. Paste the key above.
